# Chatobby 0.2.1 public alpha

Chatobby 0.2.1 pairs with Runtime 0.2.1 on Windows and experimental macOS.

> **macOS status:** Apple Silicon and Intel packages are built and verified on
> native GitHub macOS runners. This alpha has not been externally verified on a
> physical Mac and is not Apple-notarized.

## What changed

- Moved the attachment button to the far-left edge of the shared composer bar
  in both main-agent and subagent feeds.
- Removed the decorative permission-policy shield while retaining its readable
  policy name and picker.
- Hardened the release workflow so the Community-plugin metadata advances only
  after the matching GitHub release and all three connector assets are live.

Chatobby remains public-alpha software. Back up important vaults and begin with
the minimum permissions needed for the task.
